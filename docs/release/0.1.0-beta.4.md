# VoxKey 0.1.0 Beta 4

Optional local English grammar correction is now available in the published app.
Beta 3 kept these controls hidden; Beta 4 exposes the same tested model and
correction pipeline used in the local candidate.

## Turn it on

Open **Settings and Readiness… → Settings** and enable **Correct grammar locally**.
The same option appears during initial setup. It defaults off for users who have
not enabled it before; an existing candidate preference and verified model
installation are reused.

- Enabling downloads about **519 MB** and prepares about **263 MB** of local
  model assets. Progress appears beside the setting.
- Dictation remains available while the model downloads and prepares. Correction
  starts automatically when it is ready, without restarting or toggling again.
- After setup, grammar correction works offline. No audio or transcript is sent
  to the model download hosts.
- Correction runs during recording and reuses completed work at finalization.
  Long dictations are processed in bounded sections with paragraphs preserved.
- Turning it off cancels preparation and unloads the model. Missing assets or
  inference failures leave the original transcription available.

## Quality and model terms

This is an optional beta feature that may change words. In the recorded local
GPU evaluation, it corrected 20 of 24 error examples and preserved all 40 control
examples. Those small synthetic tests do not establish general accuracy.
Long text can still produce unwanted edits such as “build” → “building”.

VoxKey's source remains MIT licensed. The downloaded grammar model is separately
restricted to **noncommercial use**; its terms and attribution are included in
the app. The large model files are downloaded from their original sources,
not bundled with the DMG.

## Update

Choose **Check for Updates…**, install, and relaunch. The menu should show
**VoxKey 0.1.0 (4)**. Existing vocabulary and speech models remain in place.

## Validation

Debug and release suites passed with the installed grammar model, each reporting
218 tests passing and nine opt-in checks skipped. Packaged-app checks verified
visible, initially disabled controls, bundled model terms, and offline correction
using the signed app's own preparation resources. Light and dark UI renders,
script syntax, property lists, and whitespace checks passed.

Live microphone-to-editor behavior, actual update/restart behavior, and
performance on other Macs remain manual acceptance checks. No complete
third-party editor compatibility matrix is claimed.
