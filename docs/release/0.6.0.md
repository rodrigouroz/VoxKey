# VoxKey 0.6.0

## One Settings window

- General, Dictation, and Models & Languages are panes in one Settings window,
  with a native toolbar that keeps the current selection visible.
- Model management stays inside Settings. The menu-bar shortcut and setup's
  Choose Model action open the Models & Languages pane directly.
- Settings remembers the last-used pane and keeps model/download state when
  switching panes. Command-comma opens Settings from the app menu as well.

## Visible update reminders

- Available updates show “Update” beside the menu-bar icon and an “Update to
  VoxKey …” menu action that opens the update dialog.
- Background checks use this reminder instead of leaving an update dialog behind
  other windows. Dismissing or skipping the update clears the reminder.
- Automatic checking and automatic downloading/installing retain their existing
  preferences. Dictation and unresolved recovery still defer installation.

## Improve transcription

- A new, default-off **Improve transcription** setting removes fillers and repetitions
  and improves English grammar after dictation. It replaces the previous grammar-only
  option and requires a fresh opt-in.
- Optional models download on demand (up to 2.03 GB), then run entirely on this Mac.
  Valid existing assets are reused. No local server or additional software is needed.
- English improvement uses S1-mini with prompt lookup followed by restricted GECToR
  edits. Spanish and other dictation languages remain available without improvement.
- Disabling improvement restores raw transcription. Failed or cancelled edits preserve
  the original text. The grammar model is for noncommercial use; review improved text
  because editing can change words.

## Privacy

- Release and release-candidate builds contain no VoxKey diagnostic logging, text-trace
  recorder, trace controls, or inspection commands. Saved settings cannot enable them.
- Diagnostic code is available only to developers who explicitly enable it in a local
  Debug build. Published app and final-DMG checks enforce this boundary.

## Validation limits

Dictation has been exercised in the maintainer's normal workflow. A reported intermittent
Right Command activation failure remains unresolved; this release does not claim to fix
it. Other Macs, fresh user accounts, and all host editors have not been exhaustively tested.
