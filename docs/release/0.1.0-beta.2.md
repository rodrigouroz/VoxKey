# VoxKey 0.1.0 Beta 2

Setup now opens automatically when you launch VoxKey for the first time or when
microphone access, Accessibility access, or the English model needs attention.
This also handles installing the signed beta after a development build had already
marked setup complete. Closing setup keeps it closed for the rest of that launch.
Fully configured installs continue to start quietly in the menu bar.

## Update from Beta 1

Choose **Check for Updates…** in the VoxKey menu, then install and relaunch.
The menu should show **VoxKey 0.1.0 (2)**. If a prerequisite is missing, setup should
open automatically. Existing vocabulary and downloaded models stay in place.

This release is also our first beta-to-beta Sparkle installation test. Apple Silicon,
macOS 26+, English. Editor compatibility and live-microphone latency remain under
active testing. Please report problems using synthetic text only.
