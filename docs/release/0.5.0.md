# VoxKey 0.5.0

Send feedback directly by email and enjoy more consistent typography throughout
the app. Requires Apple Silicon and macOS 26 or later. Internal build number: 12.

## Easier feedback

- Send Feedback in Settings opens an email draft to hello@rodrigouroz.com with
  the subject “VoxKey feedback.” The address is visible and can be copied.
- Feedback links on the English and Spanish websites also open an email draft.

## Consistent native typography

App headings now use the macOS system font, matching the controls and body text.
This includes onboarding, Models and Languages, Vocabulary, Package Contents,
and Last Dictation/Safety Net.

## Clearer vocabulary copy

- Single-item counts use “1 term,” including personal terms, package details,
  search results, and import confirmation.
- Empty-state import instructions now include vocabulary ZIP files.

## Validation and limits

The automated test suite passed, including native layout and vocabulary tests.
App windows were rendered and inspected in light and dark appearances.

First-install dictation on another Mac and an end-to-end Sparkle update have not
been re-tested for this release. Editor compatibility still depends on the
destination application's macOS Accessibility support.
