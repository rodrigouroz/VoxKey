# Enable launch at login by default

After onboarding has verified required permissions and installed the selected Model Package, VoxKey enables Launch at Login by default. This makes Always Ready the ordinary experience after a restart without opening the microphone or beginning continuous capture.

Launch at Login remains visible and user-disableable in Settings. VoxKey also provides an explicit Quit action; quitting ends any active session safely, discards Ephemeral Audio, and removes the volatile Last Result. Disabling automatic launch or quitting the application does not silently re-enable it before the user next opens VoxKey.
