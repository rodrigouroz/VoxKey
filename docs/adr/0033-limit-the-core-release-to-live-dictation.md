# Limit the core release to live dictation

The Core Release accepts only deliberate Live Dictation from the current System Input Device. It does not transcribe audio files, capture meetings or system audio, batch-process recordings, monitor background speech, or interpret system-wide voice commands.

These adjacent workflows introduce different consent, retention, permissions, user-interface, and failure-recovery requirements. Adding them would weaken the Local Transcription Boundary and the Ephemeral Audio model without improving the core promise: press, speak, release, and text appears safely or remains temporarily recoverable as the Last Result.
