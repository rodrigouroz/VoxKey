# Make transcription permanently local

VoxKey performs capture, speech recognition, and transcript processing entirely on the user's Mac. Dictation audio and transcript content never leave the device, and no remote transcription provider or cloud fallback will be implemented. This permanent constraint accepts local compute, model-download, and accuracy trade-offs in exchange for a privacy guarantee that does not depend on configuration, provider policy, connectivity, or user vigilance.
