# VoxKey 0.7.0

## Live transcript preview

- Words now appear in the recording overlay while you speak, without waiting for
  a pause. Provisional words use a softer color and can change as recognition
  settles on completed phrases.
- The overlay smoothly follows the latest three lines and keeps them visible
  while VoxKey finishes processing and inserts the result. Reduce Motion disables
  the transitions, and the overlay never takes keyboard focus.
- Preview work yields to final recognition. Only the final text is inserted into
  your input; failed delivery remains recoverable through Safety Net.
- Preview text stays in memory and clears when the session completes or is
  cancelled. Late callbacks cannot restore text from an ended session.

## Focused-editor fixes

- Improved editor detection when a web view reports its page or scroll container
  as focused instead of the input inside it.
- Expanded the bounded editor search to reach composers after longer conversation
  histories, while retaining time and depth limits, ambiguous-focus rejection,
  and secure-field protection.

## Validation limits

Automated tests cover preview ordering, cancellation, final-result preservation,
native overlay layout in light and dark appearances, and focused-editor resolution.
Installed-model checks use synthetic speech. They do not establish microphone
compatibility, battery impact, or latency across all Macs and host editors.
A fresh-user installation, physical dictation session, and VoiceOver walkthrough
have not been repeated for this release. The previously reported intermittent
Right Command activation failure remains unresolved.
