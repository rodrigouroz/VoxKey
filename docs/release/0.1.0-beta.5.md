# VoxKey 0.1.0 Beta 5

This release combines Beta 4's optional grammar correction with the pending
menu and Settings improvements.

## Included

- **Launch at Login** is now in **Settings and Readiness… → Settings**.
  Its checkbox reflects macOS registration status. If approval is required,
  Settings explains where to allow VoxKey; registration failures appear beside
  the setting.
- **Toggle Dictation** remains in Settings. Its duplicate menu entry and the
  old Launch at Login menu entry have been removed.
- **Correct grammar locally** remains available in onboarding and Settings,
  alongside the new login control. It is optional and initially off, downloads
  its model separately, and lets dictation continue during preparation.
- Settings layout checks cover light and dark appearances with grammar both
  available and hidden, including long microphone names.

All previously published features are retained: configurable triggers,
microphone selection and fallback, the live input meter, vocabulary ZIP import,
and the Settings/editing fixes.

## Update

Choose **Check for Updates…**, install, and relaunch. The menu should show
**VoxKey 0.1.0 (5)**. Existing preferences, vocabulary, and downloaded models
are preserved. Open **Settings and Readiness… → Settings** to find Toggle
Dictation, Microphone, Correct grammar locally, and Launch at Login together.

Grammar uses the same model and correction behavior as Beta 4. Its separate
noncommercial terms and known quality limitations still apply; see the
[Beta 4 notes](https://github.com/rodrigouroz/VoxKey/releases/tag/v0.1.0-beta.4).

## Validation

Debug and release test suites each passed 218 tests, with nine unrelated opt-in
checks skipped. These runs included the signed app's grammar controls and reuse
of the installed model. Settings passed layout checks in all four appearance
and grammar-availability combinations, with light and dark renders inspected.

Actual launch-at-login behavior after signing out, live microphone-to-editor
behavior, and update/restart behavior remain manual acceptance checks.
