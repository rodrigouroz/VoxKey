# VoxKey 0.1.0 Beta 3

More control over how you dictate, easier vocabulary imports, and fixes for
Settings and permission handoffs. Apple Silicon, macOS 26+, English.

## What's new

- Choose Globe/Fn, Right Option, Right Command, or Right Control as your
  dictation trigger in **Settings and Readiness… → Settings**.
- Enable **Toggle Dictation** to press once to start and again to finish.
  Escape cancels, and initial silence stops capture automatically.
- Pin a microphone just for VoxKey. If it is unavailable, the next dictation
  falls back to the system default and Settings explains the change.
- See incoming audio through the live Listening meter. Silent input now shows
  **No audio detected — check the microphone in Settings**.
- Import vocabulary packages directly from ZIP files, preview their contents,
  and activate them explicitly. Unsafe or incomplete archives are rejected.
- Whisper can use all available Core ML compute units, following local
  performance testing.

## Fixes

- Settings and Readiness remain accessible through the Dock and application
  switcher while open, including during macOS permission handoffs. Reopening
  VoxKey brings its window back.
- Dictation into the built-in test field and standard editing shortcuts work
  again through the restored Paste command.
- Builds use a pinned Developer ID signing identity. Local packaging previews
  have a separate identity so they do not interfere with VoxKey's saved
  Accessibility permission.
- Content-free phrase-repetition diagnostics help investigate duplicate output;
  deliberate repeated words remain intact.

## Update

Choose **Check for Updates…** in the VoxKey menu, then install and relaunch.
The menu should show **VoxKey 0.1.0 (3)**. Existing preferences, vocabulary,
and downloaded speech models stay in place. You can also install the DMG
manually after quitting other VoxKey copies.

## Testing and limitations

The standard debug and release suites passed on September 9, 2026. Each run
reported 217 tests passing and skipped 20 opt-in hardware/model checks.
Script syntax, property-list validation, and whitespace checks also passed.

Automated tests cover trigger and capture state transitions, microphone
selection and fallback, audio-meter behavior, ZIP validation, native editing,
and delivery safeguards. Real microphone-to-editor behavior, permission
handoffs, hardware disconnects, and beta-to-beta installation still require
manual acceptance. No complete third-party editor compatibility matrix is
claimed, and local benchmarks do not establish performance on other Macs.

Optional grammar correction remains restricted to local evaluation candidates
and is not enabled in this release. Its model has separate noncommercial terms
and can make unwanted edits.

Report problems with your version/build, macOS, Mac chip, and destination app,
using synthetic text only.
