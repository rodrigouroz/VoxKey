# Remain fully functional offline

After VoxKey and a supported Model Package are installed, the complete Core Release remains usable offline indefinitely. VoxKey requires no account, sign-in, online activation, license server, subscription entitlement, periodic connectivity check, or remote configuration to become or remain Always Ready.

Application and Model Package downloads and Optional Diagnostics may use the network within their existing consent boundaries. Failure to reach those services cannot disable, degrade, time-limit, or alter an already installed transcription and Text Delivery path. VoxKey ships no remote feature flag capable of changing core behavior.
