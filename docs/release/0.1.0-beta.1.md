# VoxKey 0.1.0 Beta 1

First beta for hands-on testing. Apple Silicon, macOS 26+, English.

## Included

- Hold Globe/Fn to dictate with local WhisperKit recognition.
- Completed-phrase transcription during capture and one final tail pass on release,
  including the short-sentence latency fix.
- Safe final delivery, Escape cancellation, secure-field rejection, and volatile
  Safety Net recovery when a destination cannot be safely used.
- Personal vocabulary, package import/activation, and a read-only package viewer.
- Optional synthesized capture sounds, menu-bar setup, and status feedback.
- Sparkle updates from GitHub Releases, with signed update metadata hosted on GitHub Pages.
  Use **Check for Updates…** or enable automatic checks in the VoxKey menu.

## Known limitations

Editor compatibility and live-microphone latency are under active testing. No
complete third-party supported-app matrix is claimed. Partial results are internal;
only final text is inserted. A first model download and preparation is required.
Model downloads do not yet use a pinned authenticated manifest.
Downloaded installation and the first beta-to-beta update are being validated with
this release. This is an initial test release, not a completed compatibility certification.

## Try it

Quit any development copy of VoxKey, drag this app into Applications, and launch it.
The distribution signing identity differs from development builds, so macOS may
ask for permissions again. The menu shows **VoxKey 0.1.0 (1)**.

After installing, check for updates; it should report you are up to date. The next
beta will exercise the actual download, installation, and restart.

Report problems with version/build, macOS, Mac chip, destination app/version, and
steps using synthetic text. Never attach real recordings, transcripts, or private
vocabulary. Security reports belong in the private reporting channel in SECURITY.md.
