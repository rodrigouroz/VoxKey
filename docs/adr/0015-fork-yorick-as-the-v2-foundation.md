# Fork Yorick as the VoxKey v2 foundation

VoxKey v2 will fork Yorick's MIT-licensed code while preserving required history and attribution. The fork retains reusable macOS safety and distribution machinery such as focus capture, secure-field handling, guarded pasteboard behavior, recovery state, onboarding, signing, updates, and lifecycle scaffolding. It does not adopt Yorick's product specification: notes and history behavior, default telemetry, content logging, author-specific vocabulary, branding, transcription defaults, and oversized orchestration boundaries must be removed or replaced. The existing VoxKey prototype is a reference source for independently valuable tests or components, not the v2 foundation.
