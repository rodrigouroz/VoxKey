## Visible update reminders

- Available updates show “Update” beside the menu-bar icon and an “Update to
  VoxKey …” menu action that opens the update dialog.
- Background checks use this reminder instead of leaving an update dialog behind
  other windows. Dismissing or skipping the update clears the reminder.
- Automatic checking and automatic downloading/installing retain their existing
  preferences. Dictation and unresolved recovery still defer installation.
